# Multiprecision Pi Calculator

C言語で多倍長演算を実装し、逆正接の級数展開から円周率を小数点以下約1,000桁まで計算するプログラムです。

## 主な実装

- 配列と構造体による多倍長数の表現
- 符号、指数、有効桁の管理
- 多倍長数の加算、減算、乗算、除算
- ダーゼ、ベガ、シュテルマーの各公式による円周率計算
- 級数の収束条件による計算終了判定
- 計算時間の測定

## 結果

ダーゼの公式で小数点以下約1,000桁を計算し、参照値との比較では先頭996桁が一致しました。また、3公式の実行時間を比較し、シュテルマーの公式がダーゼ・ベガの公式より短時間で収束することを確認しました。

## 使用技術

- C
- 多倍長演算
- 数値計算
- Taylor級数

元コードは`gettimeofday`を使用しているため、CygwinやLinuxなどのPOSIX互換環境を想定しています。

## ソースコード

[`src/pi_calculator.c`](src/pi_calculator.c)

桁数はコンパイル時定数で指定しており、末尾数桁には切り捨てによる誤差があります。
3種類の公式を実装しており、現在のコードではダーゼの公式を実行する設定です。
